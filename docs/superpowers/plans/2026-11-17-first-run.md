# First-run Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the cluttered first screen with a welcome page and a step-by-step family setup for invited parents, make "Who's playing?" kids-only, add "Add a child" to the Grown-ups page, and give new players a short first-time welcome.

**Architecture:** Pure decisions (which first screen, which setup steps, does a player need the welcome, joining names) live in a new classic script `first-run-rules.js` (`window.FirstRun`), tested with Node like `pet-rules.js`. The screens live in `app.js` (one IIFE, no build step) next to the account, sync and player code they use. Styles go at the end of `style.css`.

**Tech Stack:** Vanilla JS/HTML/CSS; Node 22 `node:test`; static preview server `.claude/launch.json` name `math-quest-alt` (http://localhost:5181). PHP sync API is not available locally.

**Spec:** `docs/superpowers/specs/2026-11-17-first-run-design.md`

## Global Constraints

- Setup screens: one centered card (max ~560px), a step indicator ("Step 2 of 4") where it applies, one primary button, at most one secondary text link. Space theme throughout setup.
- Welcome line: "Practice that matches what your kids are learning in school: math, reading, writing, science, social studies and typing."
- Welcome points: "🎯 Set to each child's grade (2nd–5th), subject by subject." / "🔁 Missed questions come back until they stick." / "📊 You see what each child has mastered."
- Invite path steps: family → recovery → kids → homescreen (homescreen only on touch devices not running from the Home Screen). Local path: pin → kids → homescreen. Sign-in path: kids → homescreen.
- Children added by a grown-up: real players, theme `space`, placeholder avatar, `p.pickLook = true`.
- Kid welcome: world + look steps only when `p.pickLook`; tour when `!p.introSeen` and the player has no progress (no `stats`, `log` or `missions` entries). Existing players with progress never see it.
- Tour lines: "Pick a subject, then a mission." / "Today's Quest is a mix from every subject. A new one every day!" / "Master questions to hatch your egg!" Buttons Next (last: "Let's go!") and Skip.
- No read-aloud (synthetic voice) anywhere in the new screens.
- Errors on setup forms show inline (`role="alert"`), not only as a toast.
- No changes to `api/` (server).
- Commit messages plain, no attribution lines. Run rule tests with `node --test 'tests/*.test.js'`.
- The host caches .js for a year: new script tags in `index.html` get `?v=` automatically from `server/deploy.sh`; add new files to `sw.js` CORE and bump `CACHE`.

```js
/* Quest Academy first-run decisions (no DOM). Loaded as a plain script (window.FirstRun) and by Node for tests.
   Spec: docs/superpowers/specs/2026-11-17-first-run-design.md */
(function (root) {
  'use strict';

  // Which screen a device without a current player starts on.
  function firstScreen({ locked, players }) {
    if (players > 0) return 'profiles';
    return locked ? 'add-kids' : 'welcome';
  }

  const PATHS = { invite: ['family', 'recovery', 'kids'], local: ['pin', 'kids'], signin: ['kids'] };
  function setupSteps(path, needsHomeScreen) {
    return [...(PATHS[path] || PATHS.signin), ...(needsHomeScreen ? ['homescreen'] : [])];
  }
  function stepOf(id, path, needsHomeScreen) {
    const steps = setupSteps(path, needsHomeScreen), i = steps.indexOf(id);
    return i < 0 || steps.length < 2 ? {} : { step: i + 1, total: steps.length };
  }

  const isEmpty = o => !o || (Array.isArray(o) ? o.length === 0 : Object.keys(o).length === 0);
  function needsKidWelcome(p) {
    if (p.pickLook) return true;
    if (p.introSeen) return false;
    return isEmpty(p.stats) && isEmpty(p.log) && isEmpty(p.missions);
  }

  function joinNames(names) {
    if (names.length <= 1) return names[0] || '';
    return names.slice(0, -1).join(', ') + ' and ' + names[names.length - 1];
  }

  const api = { firstScreen, setupSteps, stepOf, needsKidWelcome, joinNames };
  root.FirstRun = api;
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
})(typeof window !== 'undefined' ? window : globalThis);
```

function bindChildForm(f, redraw, onAdd) {
  const nm = document.getElementById('kn');
  nm.oninput = () => { f.name = nm.value; };
  bindAll('[data-grade]', el => { f.grade = +el.dataset.grade; redraw(); });

    onAdd();
  };
}
